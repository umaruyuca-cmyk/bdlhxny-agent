Agent 循环与装载

固定用例分别进入三种 Agent 实现。题目、上下文、模型和工具返回保持一致，只比较实现方式。模型提议，代码裁决。

单一固定运行入口

入口输入上下文输出
私有批次 API固定 case_id 与实验配置用例版本指定的固定上下文运行记录、评测结果和公开工件
产品边界：不提供自由对话入口；公开页面不连接运行服务。

Agent 循环

  1. 语义快路径：闲聊 / 明显知识类可直接应答，不进工具循环。
  2. 否则 bind_tools 原生 tool calling：模型输出 tool_calls → 治理中间件 → Observation 回填 → 直至最终回答或预算耗尽。
  3. 无 LLM 时服务不启动；依赖缺失经 /ready 显性 degraded。
用例台词 / 唤醒包 → 快路径？ → 直接应答 → AgentLoop + ToolCard → G1–G7 裁决 → Observation → 最终文本 + blocks

工具装载：scoped | search

模式行为
scoped按场景装入固定工具子集（默认推荐）
search元工具 search_tools 检索后装载；权限先于检索；未命中可回退 scoped

search 模式下 UI 对 search_tools 节点特殊渲染（检索词 + 命中数）。

三种编排形态（裸 tool calling / LangGraph 官方 ReAct / 完整工程模式）的逐环节调用链路与工具选择对照，见 三种架构对照 · 调用链路。

ResultBlock

五类 Block（ScoreCard / AnalysisReport / SuitabilityDraft / PortfolioHealth / QuoteTable）由 Observation 直接投影，不经 LLM 改写数字。SuitabilityDraft 固定披露，禁止「适合买入」话术。
