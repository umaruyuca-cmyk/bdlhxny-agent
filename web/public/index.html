公告与使用指引

试用步骤

  1. 浏览对照结果:从「实证展示」查看最新批次的指标总览,或在「对照结果」页按组别/场景筛选;每个数字都可点击下钻到单次运行的九段明细(事件流、模型与工具调用、护栏检查、耗时与 token)。
  2. 了解题目与口径:「固定题库」查看题目清单与各组表现;「评判标准」查看每个指标的计算口径与有效样本规则;「上下文压缩」查看压缩对照的算法与结果。
  3. 发起实验(需登录):点击右上角「登录」进入内部运行台,勾选固定题号并设置实验参数(重复次数、是否包含 ReAct 组、冻结数据集、工具可见集、token 上限),提交后即可发起对照批次。
  4. 跟踪与发布:批次运行中可在运行台查看进度并支持取消;每个运行完成后可逐层下钻。批次通过发布校验后,本站公开页的数字会自动更新为该批次结果。

注意事项

  • 本站为纯静态展示:浏览不会产生任何模型调用与费用;
  • 所有数字来自发布校验后的运行工件,尚未运行的字段一律显示「未运行」,不使用估算值;
  • 当前展示的批次为过程性数据(未达有效样本门槛,仅作参考),页面已如实标注;首个正式批次发布后自动切换;
  • 公开页面没有输入入口,不接受自定义问题;实验只能按固定题号发起;
  • 实验中的全部工具调用均来自冻结数据集,不会访问任何真实外部系统。

登录说明

  • 点击右上角「登录」在当前页弹出登录框完成登录,不跳转页面;仅提供项目所有者账号,由管理员创建与分发,不开放注册;
  • 登录后右上角(GitHub 图标左侧)会出现一个隐藏入口;会话有有效期,到期自动失效;
  • 密码连续输错 5 次将锁定 15 分钟;使用完毕请在运行台点击「退出登录」,退出后返回本页;
  • 登录与运行能力仅存在于私有部署;公开镜像不包含登录与运行台。

系统定位

本系统用于Agent 实现方式的对照评测:同一题库、同一模型、同一份冻结工具数据,量化不同实现之间的可复核差异。权限、预算与红线由代码确定执行,语义理解交给模型。

系统运行两类实验:

  1. 实现方式对照:同一固定题库,对照裸 tool calling / LangGraph 官方 ReAct / 完整工程模式三组实现,量化工具选择准确率、幻觉工具率、越权泄漏率与合规违规率;
  2. 上下文压缩对照:同一长上下文用例,全量透传(full)与按预算压缩(budgeted)两种处理分别跑同一 Agent 逻辑、同一套评判标准,量化强制项保留率、关键事实出现与 token 净节省。

证据方式:全部指标由代码断言产生(判官版本 fixed-rules-v1),无 LLM 判官;未运行的数字显示「未运行」,不以估算冒充实测。

整体架构

四个服务,一条公私边界:

web(纯静态展示层) ｜ engine(私有运行 API + 三组执行器) ｜ data(题库/记录/发布登记) ｜ PostgreSQL(唯一数据来源)

公开部署只含静态站(物理排除 /lab);评测批次由项目所有者在私有侧发起,经发布校验投影为静态产物。

一次运行(实现方式对照)

登录 → 按题号发起批次 → 拉取冻结工具数据 → 三组交错执行(九类事件 + 逐步明细落库) → 九段运行工件 → 发布校验(门槛/敏感扫描/hash 复算) → 公开静态展示

上下文压缩链路

长上下文条目 → 分类(强制/可压缩/仅引用/干扰) → 预算选择与压缩 → 工作上下文 → 同一 Agent 循环 → 同一判官 → 处理报告进工件

变量隔离:实现方式对照用冻结数据隔离执行质量、金标路由隔离路由误差;压缩对照只变上下文处理策略,其余全部固定。

题库

  • 实现方式对照题库 98 道:通用工具用例 72(相似区分 / 不存在工具 / 权限确认 / 无工具 / 多工具组合)+ 领域基础题 18(对话、知识、拦截与多步示例)+ 负例 8,均存 PostgreSQL 为唯一数据来源,见固定题库。
  • 上下文压缩用例 6 套,每套 full-raw 全量与 budgeted-comp 压缩两条变体,见长短对照设计。

仓库与复现

代码在 GitHub:engine/(被测内核与对照 runner)、data/(题库与记录服务)、web/(公开展示层与私有运行台)、db/(库结构与种子)。

复现三步:① 本地启动(见 deploy/本地启动说明.md);② 登录 /lab 按题号发起批次;③ npm run publish:showcase -- --git-commit <sha> 投影到公开层。工程门禁:pytest + ruff(engine)、mvn test(data)、npm test(web)。
