固定用例，实证对照

本站是 Agent 实现方式对照的结果展示层。所有数字来自发布校验后的真实运行工件；尚未运行的字段显示「未运行」，不用估算值。

查看对照结果 上下文压缩对照 评判标准

这是什么

同一题库、同一模型、同一份冻结数据，对照裸 tool calling、LangGraph 官方 ReAct 与完整工程模式三种实现方式，以及四种上下文处理策略。实验怎么读、指标怎么算，见指标定义。

证据方式：全部指标由代码断言产生，无 LLM 判官；无效运行不计入成功率；发布工件经字段白名单与脱敏校验。

从固定用例到公开证据

固定用例（数据库为唯一数据来源） → 项目所有者经私有运行 API 发起批次 → 三种编排 × 冻结工具数据执行 → 运行工件落盘 → 发布脚本投影（白名单 + 校验） → showcase-data 静态数据 → 本页渲染

指标卡读取 /showcase-data/index.json；首页只展示最新有效批次，未达门槛的批次可在对照结果页查看并注明原因。
