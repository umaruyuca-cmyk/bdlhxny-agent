# 站点信息架构与模块内容

依据 2026-08-21 所有者反馈重构:现有站点"实证层 /showcase + 讲解层 /docs"两层混排,
导航不清晰。目标结构:**顶栏 = 模块(首页栏分模块),点击模块后侧边栏展开该模块的
细则页面**;首页集中展示项目总结、整体架构与 GitHub 地址。

## 1. 导航模式

```text
顶栏(模块级,5 项 + 外链)
  首页 | 实证展示 | 对照实验 | 引擎与治理 | 数据与运行 | GitHub(外链)
        └─ 点击模块 → 模块首页,左侧边栏展开该模块的全部细则页
侧边栏(模块内页面级)
  上半:模块页面清单(当前页高亮)
  下半:当前页的本页目录(锚点,沿用现有 scroll-spy)
```

- 每个模块一个 URL 前缀与一个模块首页;
- 公开页保持铁律:纯静态、零后端调用、无输入控件(唯一例外 /lab);
- 旧 `/docs/*` 路径 301 到新模块路径(外链不失效);`/showcase-data/` 数据管线不变。

## 2. 模块总览

| # | 模块 | URL 前缀 | 一句话定位 | 页数 |
|---|---|---|---|---|
| 一 | 首页 | `/` | 三分钟看懂项目是什么、架构长什么样、代码在哪 | 1 |
| 二 | 实证展示 | `/showcase/` | 真实运行数据驱动的对照结果(看结果) | 4 |
| 三 | 对照实验 | `/experiment/` | 实验怎么设计、指标怎么定义、题库是什么(怎么测) | 5 |
| 四 | 引擎与治理 | `/engine/` | 被测系统的实现:循环、装载、目录、中间件、护栏(怎么实现) | 6 |
| 五 | 数据与运行 | `/ops/` | 数据库、冻结数据、运行 API、工件发布、部署(跑在什么上面) | 5 |

## 3. 模块一:首页 `/`

单页,回答"这是什么项目"。侧边栏即本页目录(四节)。

### 3.1 项目定位与总结

- **是什么**:Agent 编排模式对照实证平台(Touchstone)。不是公开聊天产品,不提供自由对话;
- **怎么做**:固定条件下的对照实验——同一 18 题固定题库、同一 LLM、同一份冻结工具数据,
  对照三种编排形态:**裸 tool calling** / **LangGraph 官方 ReAct** / **完整工程模式**;
- **测什么**:三个可量化能力——工具选择准确率、幻觉抑制(数字接地)、权限与合规拦截;
- **核心主张**:"模型提议,代码裁决"——语义判断归模型,权限/预算/红线等不可挽回决策由
  代码查表与中间件确定执行;交易类工具物理上不在工具目录;
- **证据方式**:全部指标由代码断言产生,无 LLM 判官;无效运行不计入成功率;
  页面数字全部来自真实运行工件,未运行显示"未运行"。

素材:现 `docs/index` 核心主张/三能力两节 + `showcase/index` 定位段。

### 3.2 整体架构

- **服务拓扑图**:web(纯静态展示) / engine(私有运行 API + 三组执行) / data(固定题库
  与运行记录) / PostgreSQL(唯一真源);公私边界:公开部署只含静态站,零密钥零后端;
- **一次运行的流程图**:项目所有者登录 → 按题号发起批次 → 冻结数据集加载 →
  三组编排执行(治理中间件/输出护栏) → 运行工件落盘 → 发布脚本投影校验 →
  公开实证层渲染;
- **三个对照变量的隔离**:编排形态是唯一变量(工具执行质量用冻结数据隔离、
  路由误差用金标路由隔离)。

素材:现 `docs/index` 整体架构/固定批次链路两节 + `docs/comparison` 调用链路图。

### 3.3 当前进展与关键数字

- **已落地清单**(截至 2026-08):fixture 单一真源、init.sql、LLM 配置可配置化、
  私有运行 API(登录/批次/工件)、/showcase 四页与发布管线、/lab 私有运行台;
- **关键数字卡片**:读 `/showcase-data/index.json` 的最新批次,三能力指标
  基线→对照渲染;未发布或未达门槛时明示(沿用现有诚实约定);
- **路线图一行**:P3-1 统一工件与有效性分类 → P3-5 发布全量校验 → P3-2 上下文接入。

### 3.4 仓库与复现

- **GitHub 地址**:https://github.com/umaruyuca-cmyk/bdlhxny-agent(顶栏常驻外链);
- **目录一览**:engine / data / web / db / deploy / docs 六目录职责一句话;
- **复现三步**:本地启动(→ 数据与运行模块)→ /lab 或 CLI 发批次 → 发布命令;
- **工程门禁**:engine(pytest 210 + ruff)、web(npm test)、data(mvn test)。

## 5. 模块三:对照实验 `/experiment/`(怎么测)

侧边栏:实验设计 / 指标定义 / 判官说明 / 固定题库 / 如何复现。

### 5.1 实验设计

- 两类实验**严格分开**:Agent 实现方式对照 vs 上下文策略对照,同一张表不混两种变量;
- 公平运行条件(11 项固定):用例版本、问题文本、数据快照、Agent 代码版本、模型与温度、
  工具目录、token 计算、上下文预算、运行限制、评测器、样本数——唯一变量写明;
- 无效运行定义(429/余额不足/服务不可用不进能力指标)与五次有效重复门槛
  (**现状**:交错运行与门槛判定属 P3-4,页面诚实标注"设计目标,未落地");
- 三组形态定义:裸 tool calling(全量工具无治理)/ 官方 ReAct(框架默认编排)/
  完整工程模式(scoped 装载 + G1-G7 + 快路径 + 输出护栏)。

素材:现 `docs/comparison` + 评测文档 §2-§6。

### 5.2 指标定义

- 能力指标 6 项:工具选择准确率、幻觉工具率、越权泄漏率、数字幻觉率、C-1 违规率、
  C-2 违规率——每项:定义原文、计算口径、方向(高好/低好);
- 效率指标 4 项:平均轮次、平均 token、p50/p95 时长;token 估算口径说明
  (API usage 优先,缺失时 chars/4 近似并标注)。

素材:现 `docs/eval` 能力三节 + 评测文档 §7。

### 5.3 判官说明

- 全部代码断言:成功执行集==期望集(集合相等)/ 目录外工具名扫描 / absent_tools 越权交集 /
  数字接地检查 / C-1 C-2 语义扫描;无 LLM 判官的原因;
- GoldRouter 金标路由:路由误差隔离手段,Treatment 组专用;
- 冻结执行器:三组共用同一冻结数据集,隔离工具执行质量差异。

素材:现 `docs/eval` 判官节 + ab_eval 判定函数语义。

### 5.4 固定题库

- 18 题全量表格:题号 / 场景 / 问题原文 / 预期工具 / 快路径标注;
- 场景覆盖分布:闲聊 1、知识 1、拦截 2、金融研究 7、组合 4、适合度 2、多步 1;
- 单一真源声明:题库存于 PostgreSQL(init.sql 固定用例段),页面与库同步由测试守卫;
- 预期怎么读:expected_tools(集合相等)/ absent_tools(不得调用)/ fastpath(金标快路径)。

素材:现 `docs/cases`(含 init.sql 同步守卫测试)。

### 5.5 如何复现

- 路径 A(/lab):登录 → 勾选题号 → 发起批次 → 轮询完成 → 发布命令;
- 路径 B(CLI):`python -m bdlh_runtime.evaluation.ab_eval --runs 5` 参数说明;
- 发布:`npm run publish:showcase -- --git-commit <sha>` 产物与校验说明(链接到运行模块)。

## 6. 模块四:引擎与治理 `/engine/`(怎么实现)

侧边栏:Agent 循环 / 工具装载 / 工具目录 / 治理中间件 / 输出护栏 / 工具清单。

### 6.1 Agent 循环

- 运行入口契约(AgentTurn:用户/场景/登录态/历史/题号);
- 循环结构:路由 → 装载 → bind_tools → 模型轮次 → 执行 → 标准化 → 汇总;
- 语义快路径:chitchat/knowledge/forbidden 三类、相似度阈值与校准记录
  (2026-08-18 qwen3-embedding 实测)、未命中回落完整管线;
- 输出契约:SSE 事件类型表 + ResultBlock 五类投影(数字不经 LLM 改写)。

素材:现 `docs/agents`。

### 6.2 工具装载

- scoped:场景 → 技能 → 依赖闭包 → 可见工具集;
- search:检索式装载与回退(research 宽包);
- 选择性装载是对照变量之一(裸调用组全量工具,完整模式组 scoped)。

### 6.3 工具目录

- 数据库单一真源(七张表:操作证/工具集/能力/技能/关联表),引擎启动 fail-fast 校验;
- ToolCard schema:name/parameters/required_arguments/adapter/只读/需登录;
- 四层模型:操作证(资格)→ 工具集 → 能力 → 技能;种子漂移由测试守卫。

### 6.4 治理中间件

- G1 可见性 / G2 只读 / G3 权限 / G4 预算 / G5 参数 / G6 来源 / G7 审计——
  每关一句话职责 + 拦截示例;
- 红线物理化:交易类工具不在目录中(不是靠提示词约束)。

素材:现 `docs/skill` 治理节。

### 6.5 输出护栏与红线

- 数字接地:答案中的非平凡数字必须能追溯到某条 Observation,违规由护栏修正;
- C-1(交易语义)/ C-2(适当性结论)红线与修正策略;
- 数据质量拦截:MOCK/TEST_FIXTURE 标记 → NON_PRODUCTION_DATA(反 mock 防线)。

### 6.6 工具清单

- 16 个工具按域分组:market(8)/ portfolio(3)/ user(1)/ analysis(1)/ research(2)+ 元工具;
- 每项:名称、一句话用途、只读、是否需登录;与目录单一真源同步守卫。

素材:现 `docs/tools`。

## 7. 模块五:数据与运行 `/ops/`(跑在什么上面)

侧边栏:数据库与冻结数据 / 私有运行 API / 工件与发布 / 部署与边界 / 路线图。

### 7.1 数据库与冻结数据

- init.sql 单一初始化入口(8 段,含建表/题库/工具目录/账号表/冻结数据);
- 核心表族:固定用例与版本 / 批次与运行 / 上下文策略 / 工具目录七表 / 冻结 fixture / 账号会话审计;
- 冻结数据集 ab-eval:18 条工具返回、call_key 规则(基准键+标的覆盖键)、
  为什么冻结——隔离执行质量差异,唯一变量是编排形态。

素材:db/docs 总体设计 + frozen_observations 模块文档。

### 7.2 私有运行 API

- 登录与会话:24h 过期、5 次失败锁 15 分钟、防枚举、审计落库;
- 批次接口:只接受 case_ids/runs/include_react/model 四字段,问题正文/提示词/工具列表被拒;
- 并发上限与作业轮询;CORS 默认关闭(仅 /lab 配置白名单)。

素材:run_api + 登录设计任务书。

### 7.3 工件与发布

- 运行工件落 ARTIFACTS_DIR(批次 JSON);
- 发布脚本:白名单投影 → schema 校验 → 禁止字段扫描 → 写 showcase-data;
- 三个数据契约(index/batch-report/run);UNCLASSIFIED 与 is_formal=false 的诚实标注
  (待 P3-1 有效性分类落地后升级)。

素材:web/schema/README + 发布脚本注释。

### 7.4 部署与边界

- 三种部署形态表:本地完整 / 云镜像 / 纯公开(只有静态站);
- 公开镜像物理排除 /lab;密钥管理约定;本地启动说明(链接 deploy/本地启动说明.md)。

### 7.5 路线图

- P3-1 统一运行工件与 VALID/INVALID 分类(评测可信度的地基);
- P3-5 发布全量校验(敏感扫描、hash 链、有效样本门槛);
- P3-2 上下文构建器接入三种运行(上下文对照页数据的来源);
- 引用两份任务清单(生产化修改任务清单 / 前端展示任务清单)的执行记录。
