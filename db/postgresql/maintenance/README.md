# 维护和数据保留

本目录记录数据库维护规则，不保存生产脚本、备份文件或访问凭证。

## 保留规则

- 固定用例版本、固定数据版本和已发布批次长期保留；
- 失败与无效运行至少保留到问题复盘结束；
- 未发布临时批次按环境配置保留 30～90 天；
- 删除批次前检查是否被 `publications` 引用；
- 大文本和录屏由对象存储管理，数据库只保存引用和 hash。

## 备份规则

- 私有 PostgreSQL 需要定期全量备份和按云平台能力开启时间点恢复；
- 恢复演练必须使用隔离环境；
- 备份文件不得提交 Git；
- 数据库密码和对象存储凭证只通过部署环境注入；
- 公开静态站不持有数据库备份或连接信息。

## 清理规则

- 清理任务分批执行，避免长事务锁住运行写入；
- 先清理无引用的外部工件，再清理对应元数据；
- 不为了提高成功率删除失败运行；
- 清理结果需要记录批次、范围、数量和执行时间。
