工具清单

统一工具目录（ToolCard）当前登记 18 个工具，按工具族分组管理。真源是引擎启动时从数据库 Registry 加载的目录（catalog_from_snapshot），本页由同步测试守卫——目录增删工具而页面未跟上即测试失败。所有工具只读（C-1 红线：交易语义工具物理不注册）；本地与 MCP 工具走同一治理拦截链。
